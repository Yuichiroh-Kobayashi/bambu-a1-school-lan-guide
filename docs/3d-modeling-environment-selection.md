卒業した生徒が、夏休みに学校へ遊びに来ました。

私の顔を見るなり、「3Dプリンタ使ってるよ」と声を掛けてくれました。

話を聞くと、家庭に、あまり使われていなかった3Dプリンタがあり、中学校の授業で使ったTinkercadで小物を作って造形しているとのことでした。「お父さんより私の方が使っている」とも話していました。

一人の後日談であり、授業効果を一般化する証拠ではありません。それでも、学校で初めて触れた道具へ卒業後も自分でアクセスでき、家庭の別の3Dプリンタでも使い続けられたことは、3Dモデリング環境を選ぶ意味を改めて考えるきっかけになりました。

この記事では、学校の3Dモデリング環境を、機能数や価格だけではなく、次の一連の流れで考えます。

```text
作成する
  ↓
保存する
  ↓
別端末から再開する
  ↓
教員が確認する
  ↓
行方不明になった作品を救出する
  ↓
STL等へ書き出す
  ↓
スライサーへ渡す
  ↓
造形する
  ↓
学校を離れた後にも学んだことを使える
```

本記事で端末を比較するとき、主に次の学校環境を想定しています。

- **iPad / Chromebook**：GIGAスクール構想で整備された1人1台端末
- **Windows**：学校のPC教室に設置された共用PC

## 1. この記事の立場と限界

この記事は、製品の性能試験や教育効果の比較研究ではありません。

根拠としているのは、主に次の内容です。

- 公立中学校で実施した、約160人を対象とする3Dプリント授業
- 協力校の有志教員3名によるTinkercadとOnshapeの試用
- 技術科教員向け研修で得た情報
- 創Webの期間限定試用
- 各製品の公式資料
- Blenderの授業利用に向けた構想

協力校では、情報、数学、美術を担当する3名の教員にTinkercadとOnshapeを試してもらいました。全員が3D-CADを初めて操作し、3名ともTinkercadの方が使いやすいと答えました。

人数の少ない試行であり、中学校や普通科高校全体へ一般化できる結果ではありません。一方、3D-CADを授業へ導入するには、生徒向け教材だけでなく、教員が短時間で操作の意味を理解し、授業を組み立てられることも要件になると実感しました。

夏季休業後半に参加した技術科の研修でも、3D-CADの例としてTinkercadが紹介されていました。東京書籍の中学校技術科FAQでも、教科書の3D-CADモデルにはTinkercadが使用され、ほかの教育向けCADとして国内製品が紹介されています。

この記事に記載する製品情報は、2026年9月時点で確認した内容です。クラウドサービスの機能、料金、対応端末、アカウント条件は変更されるため、導入時には公式情報を再確認してください。

<a id="first-cad"></a>
## 2. 初めて触るCADをどう考えるか

私は、生徒が初めて触れるCADを、特定の教材や特定の工程だけへ強く最適化された専用環境にすることには、かなり慎重です。

学校で使える時間は限られています。製品固有のボタン配置や保存操作だけを覚え、卒業後にその製品へアクセスできなくなれば、学んだ操作技能をそのまま使う機会は少なくなります。

限られた授業時間を使うなら、できるだけ次の道具へ持ち出せる知識や技能を残したいと考えています。

例えば、次の概念は製品が変わっても使えます。

- 3次元座標と視点
- 寸法と単位
- 形状の追加・削除・結合
- 部品と組み立て
- 寸法や条件を変えた設計変更
- ローカルファイルとクラウド上の設計データ
- STL等の交換形式
- 画面上で完成して見える形と、製造可能な形の違い

一方、専用CADそのものを否定しているわけではありません。

専用CADが、一般的なCADでは手間のかかる操作を減らし、次のような本来の学習へ時間を振り向けられるなら、採用する理由があります。

- 材料の厚さや規格を考える
- 部品同士の接合を考える
- 組み立て順序を確認する
- 木取りと切りしろを考える
- 限られた材料内で設計する
- 作品の寸法と構造を比較する

つまり、判断したいのは「専用CADか汎用CADか」だけではありません。

> **初めてのCADで何を学び、その知識や技能を次の環境へどこまで持ち出せるか**

を明確にする必要があります。

木工の本題へ早く到達するために専用CADを使うことと、CADそのものの基本概念を学ぶために汎用的な環境を使うことは、目的が異なります。

**端末と提供形態**

### iPadではTinkercad / Onshapeの専用アプリを推奨する

TinkercadとOnshapeはWebサービスとして利用できますが、**本記事ではiPad上でブラウザ版を使うことを一斉授業の標準にはしません**。

PC向けのWeb UIを指で操作すると、細かな選択、右クリック相当の操作、画面内の小さなボタンなどで操作しにくくなるためです。

Tinkercadには公式のiPadアプリがあります。Onshapeにも公式のiPadアプリがあり、タッチ操作用のインターフェースとジェスチャーが用意されています。

そのため、端末ごとの標準的な導線は次のように考えます。

```text
Windows PC教室
  → Tinkercad / Onshape はブラウザ

Chromebook GIGA端末
  → Tinkercad / Onshape はブラウザ

iPad GIGA端末
  → Tinkercad / Onshape は専用アプリを推奨
```

なお、Onshapeの教員向けClasses / Assignmentsは、モバイル版では機能が制限されます。クラス作成や課題管理といった教員側の作業は、WindowsやChromebookのブラウザを中心に行う方が運用しやすいと考えています。

この表は順位表ではありません。

同じ「3Dモデルを作る」ソフトでも、目標と運用が異なります。

<a id="requirements"></a>
## 4. 学校で確認する要件

学校の3Dモデリング環境は、「形を作れるか」だけでは選べません。

少なくとも、次の観点で確認します。

### 学習目的

- 3Dプリントを短時間で体験するのか
- 寸法や拘束を使って機械部品を設計するのか
- 木工作品の部品・組み立て・木取りを扱うのか
- 3Dコンテンツ、映像、アニメーションを制作するのか

### 利用開始

- 生徒アカウントが必要か
- 教員が一括登録・招待できるか
- 初回ログイン後に言語、単位、操作方法の設定が必要か
- 40人が同じ授業時間内に作業開始できるか
- GIGA端末でアプリ配布が必要な場合、MDMで事前配布できるか

### 端末をまたいだ継続

- iPad / Chromebookで作成した作品を、Windows PC教室から開けるか
- 端末間で実ファイルを受け渡さなくても同じ作品へ戻れるか
- PC教室の端末が変わっても作業を続けられるか

### 作品の正本

ここでいう「作品の正本」とは、生徒が次回も編集を続ける元データです。

- クラウド上に自動保存されるか
- 端末内のファイルとして保存するか
- ブラウザ内部に保存するか
- 別のPCやiPadから同じ作品を開けるか
- 同名ファイルや修正版を区別できるか

### 教員による確認と救出

- クラス単位で作品を一覧できるか
- 生徒の作業途中のモデルを開けるか
- 提出に失敗しても教員が作品を回収できるか
- 誤操作前の状態へ戻せるか
- 卒業・転出時に必要なデータをどう扱うか

### 3Dプリントへの接続

- STL等へ書き出せるか
- Windows PC上のスライサーへ渡せるか
- 寸法と単位が維持されるか
- 造形可能なモデルかを検査できるか

### 運用と継続

- 利用料金と契約主体
- UI更新と教材の維持
- 教員向け研修
- 問い合わせ先
- 卒業後も生徒自身が利用できるか

無料であることには価値があります。しかし、有料製品の費用には、国内向け教材、問い合わせ先、授業管理、継続的な改善が含まれる場合があります。価格だけでは判断しません。

<a id="observations"></a>
## 5. 試行から見えたこと

### 中学校の3Dプリント入門

初年度の卒業記念プレート授業では、Tinkercadを使いました。

生徒はテンプレートの文字や装飾を変更し、3Dモデルの表面形状を保存するSTL形式で書き出し、Bambu Studioでスライスしました。提出に失敗した場合でも、教員がTinkercadクラスから作品を開き、STLとして回収できました。

この経験から、授業用ツールでは「生徒が操作できること」と同じくらい、「教員が途中状態を確認し、失敗から復旧できること」が重要だと分かりました。

### 3D-CADを初めて使う教員

協力校の情報・数学・美術の教員3名には、TinkercadとOnshapeを試してもらいました。

3名ともTinkercadを使いやすいと答えました。製品の優劣を示す比較試験ではありません。それでも、短時間で導入するなら教員の側にも操作を始めやすさが要る、という一例にはなります。

情報Ⅱの理念を3Dモデリングやデジタルファブリケーションまで広げて実現するなら、アプリの導入だけでは足りません。教員自身が、3D空間、CADの種類、設計データ、スライス、造形までを理解する研修も必要です。

夏季休業後半に参加した技術科の研修でも、3D-CADの例としてTinkercadが紹介されていました。中学校や普通科高校の初回導入では、まず形を作るところまで到達しやすい環境が選ばれやすいと考えられます。

### 卒業後の利用

冒頭の卒業生は、学校で使ったTinkercadを家庭でも利用していました。

この一例だけで、授業の効果やTinkercadの一般的な優位性は判断できません。

それでも、

- 無償でアクセスできる
- 学校外の端末でも利用できる
- 家庭にある別メーカーの3DプリンタへSTLを渡せる
- 学校で覚えた操作を、自分の目的で使い直せる

という状態は、学校で学んだ技術を学校の中だけに閉じない一例です。

私は、このような状態を技術の大衆化の一つと捉えています。

<a id="tinkercad"></a>
## 6. Tinkercad：3Dプリントへの入口

Tinkercadは、無償で利用できる3Dデザイン環境です。

WindowsやChromebookではWebブラウザから利用でき、iPadには公式アプリがあります。

基本形状を配置し、足し合わせたり、穴形状を使って差し引いたりすることで、短時間に立体を作れます。

初回の3Dプリント題材で有効だった点は次です。

- 文字や基本形状へすぐ到達できる
- テンプレートを配布できる
- Windows、Chromebook、iPadをまたいで利用しやすい
- Classroomsで生徒を管理できる
- 教員が生徒作品を確認できる
- 生徒が提出に失敗しても、クラス内の作品から回収できる
- STLとして書き出し、メーカーの異なる3Dプリンタへも渡せる

Tinkercadは、寸法拘束、設計履歴、複雑なアセンブリを中心とした機械CADではありません。

一方、3D空間で形を組み合わせ、寸法を確認し、STLへ書き出して実物へつなげる入口としては、操作開始までの負担が小さい環境です。

### GIGA端末での利用

Chromebookではブラウザ利用が基本です。

iPadでもWebサイトは開けます。ただし本記事では、授業利用にiPadアプリを推奨します。タッチ操作を前提としたアプリの方が、細かな3D操作を一斉授業で説明しやすいためです。

### アカウント運用

教員はTinkercadのClassroomsを利用できます。

生徒側は個人のAutodeskアカウントを利用する方法だけでなく、Class Seatsを使い、教員が用意したStudent loginとクラスコード等で参加させる方法もあります。

この点は、低年齢の生徒や、学校で生徒個人の外部サービスアカウントを増やしたくない場合に大きな利点です。

Tinkercadを選ぶ理由は、「簡単だから」だけではありません。

> **学校外からもアクセスでき、教員がクラス内のデータを追跡でき、特定メーカーの3Dプリンタに閉じない**

ことが、授業運用と継続利用の両方に効きます。

<a id="onshape"></a>
## 7. Onshape：普通教育から本格的な機械CADへ

Onshapeは、ブラウザで動作するクラウドネイティブのCAD・PDM環境です。

スケッチ、寸法拘束、幾何拘束、押し出し、穴、フィレット、アセンブリ、図面などを扱えます。形を直接並べるだけでなく、設計意図を寸法や関係としてモデルへ保持できます。

教育向けにはStudent PlanとEducator Planがあり、Educator PlanではClasses & Assignmentsを利用できます。より大規模な組織管理、SSO、一括ユーザー管理などはEducation Enterpriseが対象です。

Onshapeの強みは、専門的な機械CADを、特定のPC教室へ閉じず、クラウド上の一つの設計データとして扱えることです。

- Windows / Chromebookではブラウザから利用できる
- iPadにはタッチ操作向けの公式アプリがある
- 設計データをクラウド上の一つの正本として扱える
- 端末を替えて作業を続けられる
- 教員がクラスと課題を管理できる
- 設計変更と履歴を扱える
- 機械製図へ発展できる

### iPadではアプリを推奨する

OnshapeはWeb CADですが、iPad授業でPC向けブラウザUIをそのまま使うことは、本記事では推奨しません。

公式のiPadアプリには、タッチ用のジェスチャー、スケッチ、拘束、寸法、Part Design、Assembly操作が用意されています。

したがって、iPadをGIGA端末として使う学校では、

```text
生徒：Onshape iPadアプリ
教員のクラス管理：Windows / Chromebookのブラウザ
```

という役割分担が現実的です。

### 初回設定と教員養成

Tinkercadよりも、利用開始前と操作習得の負担は大きくなります。

初年度の検討では、招待された生徒について、日本語表示、再サインイン、既定単位の確認などが必要でした。この初回設定の流れは、旭川工業高等専門学校の大柏哲治先生が作成した[Onshape Education Enterpriseから招待されたときの設定方法](https://onshape.thick.jp/onshape/wp-content/uploads/2026/02/Education-Enterpriseから招待された学生の設定20260225.pdf)に、画面付きで整理されています。この資料は2026年2月に公開されたもので、2025年度の選定後に確認しました。当時の判断根拠ではありません。

また、スケッチ、拘束、寸法、フィーチャーという機械CADの考え方を学ぶ必要があります。

これは欠点というより、学ぶ内容が異なるためです。

短時間で記念品を作る題材には重くても、

- 寸法に基づく設計
- 設計変更
- 部品の組み立て
- 機械製図
- 設計履歴

を学ぶなら、Onshapeの方が本題に合います。

卒業後については、学生向けのサブスクリプションを終了した後も、非営利用途の無償プランへ移って使い続けられます。ただし無償プランで作成したデータは公開扱いになるため、扱う題材によっては注意が要ります。

協力校の教員3名による短時間の試用では、全員がTinkercadを使いやすいと答えました。情報Ⅱや普通教育でOnshapeを活用するには、生徒向け教材だけでなく、教員が機械CADの考え方を理解する研修も必要です。

Onshapeの価値は、機械CADを単純化したことだけではありません。

> **プロフェッショナルなパラメトリックCADの考え方を、ブラウザやiPad、クラウド保存、教育向けクラス機能を通じて普通教育から触れられるところまで持ってきた**

ことにあると考えています。

<a id="shapr3d"></a>
## 8. Shapr3D：iPadから始める直感的なCAD

Shapr3Dも比較対象に残す価値があります。

TinkercadやOnshapeと同じWeb CADではありません。Windows、macOS、iPadOSなどへアプリをインストールして利用し、Shapr3D Cloud / Syncによって端末間で設計データを同期する環境です。

特にiPadとApple Pencilを使ったモデリングに強く、画面上の形へ直接触れるように操作できます。

### 対応端末

本記事で想定する学校環境では、次の位置付けです。

- Windows PC教室：利用可能。ただしアプリのインストールが必要
- iPad GIGA端末：主要な利用環境
- Chromebook GIGA端末：モデリング環境としては利用できない

そのため、

```text
iPadでモデリング
  ↓ Shapr3D Sync
Windows版Shapr3Dで開く
  ↓ STL / 3MF
Bambu Studio
```

という経路は成立します。

一方、

```text
Chromebookでモデリング
  ↓
Windowsブラウザで続きを開く
```

というTinkercadやOnshapeの経路には入りません。

### 学校利用で気になる点

Shapr3Dを学校で使う場合、次を確認する必要があります。

- 生徒ごとのShapr3Dアカウント
- アプリの一斉配布と更新
- 教育ライセンスの提供地域と申請条件
- PC教室とiPadの両方へアプリを準備するか
- 教員が生徒作品をクラス単位で確認・救出する方法
- 卒業後に教育ライセンスが終了した場合のデータ取扱い

教育ライセンスは無償のPro相当として提供されていますが、提供地域の再編が行われているため、導入時点の条件を確認する必要があります。

### 本記事での位置付け

Shapr3Dは、

> **iPadを単なる閲覧端末ではなく、本格的な3D設計端末として使いたい場合**

には有力です。

ただし、GIGA端末がChromebookの学校では共通教材にできません。教員がクラス単位で作品を管理する点でも、TinkercadやOnshapeの方が扱いやすいと考えています。

そのため、本記事では主要な採用候補というより、**iPad中心の学校における別解**として位置付けます。

<a id="tsukuru-web"></a>
## 9. 創Web：木工作品の設計へ特化した環境

創Webは、山崎教育システムが提供する、中学生の木工作品を想定したWeb型の3D-CADです。

夏季休業中の無料体験期間にWindows端末で試用しました。

試用時に入手した説明書では、次の工程を一つの環境で扱っていました。

- 板材の部品作成
- 部品の厚さ、木目、繊維方向の設定
- 部品の組み立て
- 部品図
- 組み立て図
- 木取り図
- 切りしろ
- STL出力

説明書の本立て例では、底板、側板、背板を作成し、平面図・正面図・側面図・透視図を見ながら組み立て、部品図と木取り図まで作成します。

私も、授業で製作する棚付き本立てに近いモデルを試しました。特に板材の部品作成と組み立ては円滑でした。一般的な3D-CADで板材を一枚ずつ作り、向きを調整して組み立てるより、木工作品の手順に沿っています。

説明書では、端末へのファイル保存、ブラウザへの保存、iOSの「ファイルに保存」が示されています。

一方、試用時には次を十分に確認できませんでした。

- ブラウザ保存の永続条件
- 別端末からの継続
- 教員によるクラス管理
- 生徒作品の提出・返却
- 提出に失敗した作品の教員による救出

創Webは、木工教材をそのまま3Dモデル化し、部品図・組み立て図・木取り図へつなげる目的には適しています。

木工の教材そのものをモデリング課題にするなら、Tinkercadより少ない操作で本題へ到達できる可能性があります。

一方、卒業した生徒が自分で使い続ける道は見当たりませんでした。学校向けの製品であり、個人が学校外で利用を始める手順を確認できていません。授業で覚えた操作を卒業後も使えることを条件に含めるなら、ここは弱点になります。

ただし、初めて学ぶCADとして採用するなら、木工専用の操作だけで終わらせず、

- 3次元空間
- 寸法
- 部品
- 組み立て
- 図面
- 設計変更

など、ほかの設計環境にもつながる概念を意識して扱いたいと考えています。

<a id="cadiy3d"></a>
## 10. caDIY3D for Education：木工特化と授業管理の統合

caDIY3Dにはデスクトップ向け製品もありますが、現在の`caDIY3D for Education`は教育機関向けのWebアプリです。

公式情報では、Windows、Chromebook、iPadに対応し、インストール不要で利用できます。GIGAスクール構想で導入された標準的なChromebookでの利用も想定されています。

令和8年版（2026年版）では、木工作品の設計機能に加えて、学校運用へ直接関係する機能が示されています。

- クラス作成
- 生徒の個別登録とCSV一括登録
- ニックネームとパスワードによる生徒ログイン
- 提出済み・確認済み・返却済みの状態管理
- 教員による提出物の確認
- 提出物のZIP一括保存
- 掲示板と参考図面の共有
- 初学者向けチュートリアル
- 材料取り図
- 材料数の制約チェック
- 材料同士の接触面の可視化

これは、私が3Dプリント授業で重要だと感じた、

> **生徒のデータを行方不明にせず、教員が確認し、必要なときに救出する**

という要件へ正面から対応しています。

### 専用CADとしての評価

caDIY3D for Educationは、材料加工、とりわけ木工作品の設計へ強く最適化されています。

私の立場から見ると、生徒が最初に触る唯一のCADとして採用することには慎重です。

一方、

> **木工作品の設計・組み立て・材料取りを扱う授業で、CAD操作そのものではなく材料加工の学習へ時間を使う**

ことを目的とするなら、この専用性は明確な利点になります。

さらに、TinkercadやOnshapeとは異なる形で、学校向けのクラス管理と提出管理まで製品内に持っている点は高く評価できます。

caDIY3D for Educationは学校向けのWebアプリです。卒業した生徒が個人で同じ環境を使い続けるには、インストール版の有料製品へ移ることになります。木工設計に絞った操作体系である点と合わせて、卒業後の継続利用という観点では制約があります。

現時点では公式情報を調べた段階であり、自校の端末とネットワークでは試していません。

特に確認したいのは次です。

- 生徒登録とログインの実作業
- iPad / Chromebook でのタッチパネル中心の操作
- 教員が未提出状態の作品まで確認・救出できる範囲
- クラスをまたぐ年度更新
- 卒業・転出時のデータ取扱い
- クラウド保存とローカル書き出しの関係
- STL等による3Dプリントへの接続
- 費用とサポート範囲

次に実機検証したい教育用CADです。

<a id="blender"></a>
## 11. Blender：3Dコンテンツ制作という別の系統

Blenderは、Tinkercad、Onshape、木工向けCADと同じ軸だけでは比較できません。

機械部品や板材を寸法で設計するCADというより、頂点・辺・面からなるメッシュを編集し、3Dコンテンツを制作する環境です。

- 自由形状
- ローポリゴンモデル
- キャラクター
- レリーフ
- レンダリング
- アニメーション
- 映像
- 3Dプリント

へ展開できます。

高校「情報Ⅱ」で、同じ3Dデータを画像、映像、3D表示、3Dプリントへ展開する題材には、Blenderが合います。

### PC教室向けの利点

BlenderはWindowsへインストールして使うアプリですが、通常の利用に生徒ごとのオンラインアカウントを必要としません。

また、OSSであり、LTS版やポータブル版を利用できます。

そのためPC教室では、

- 全端末を同じバージョンへそろえる
- 単元中は更新しない
- 教材画面と実際のUIを一致させる
- ネットワーク障害時もローカルでモデリングする

といった管理がしやすい点があります。

### 3Dプリントでは検査が必要

Blenderでは、見た目が立体でも、

- 面の欠損
- 内部面
- 法線反転
- 非マニフォールド
- 極端な薄肉

などによって、3Dプリントに適さないモデルになる場合があります。

機械CADではソリッドとして成立しない形状がエラーになりやすいのに対し、Blenderでは不完全なメッシュでも編集を続けられます。

そのため、3Dプリント授業では、

```text
モデリング
  ↓
寸法・スケール確認
  ↓
メッシュ検査
  ↓
STL出力
  ↓
Bambu Studioでレイヤープレビュー
```

までを一つの工程にする必要があります。

### Application Template構想

Blenderは多機能です。初めて使う生徒に、そのまま全機能を見せると、必要な操作へ到達するまでの負担が大きくなります。

将来的には、BlenderのApplication Templateを使い、3Dプリント授業に必要な機能へ画面と初期設定を絞ることを検討しています。

例えば、次の機能です。

- 基本形状を追加する
- 文字を追加する
- 移動・回転・拡大縮小を行う
- 形状を結合・差し引きする
- 寸法と単位を確認する
- 非マニフォールドや薄肉を検査する
- STLを書き出す

ただし、授業用テンプレートは現時点では構想段階です。実装済みの教材ではありません。

BlenderにはTinkercad、Onshape、caDIY3D for Educationのような標準のクラス管理機能がありません。作品の保存、提出、版管理、教員による確認・救出は、学校側のファイル運用として設計する必要があります。

<a id="paper-drawing"></a>
## 12. 木工では紙の図面を残す

東京書籍のFAQでは、3D-CADを、手描き製図や空間認識に苦手さがある生徒への手立てとして使えることが紹介されています。生徒に操作させることが難しい場合は、教員が作成した3Dモデルを提示して完成イメージを補う方法も示されています。

この使い方には価値があります。

創Webの説明書でも、本立てを部品ごとに作成し、平面図・正面図・側面図・透視図を行き来しながら組み立て、部品図や組み立て図、木取り図へつなぐ構成になっています。

紙の図面だけでは完成形を想像しにくい生徒に、3Dモデルを提示することは有効な支援になり得ます。

一方、私の木工授業では、紙の図面を中心にします。

空間認識が苦手な生徒には、完成見本を提示して説明します。紙の図面から形を読み取ること自体も、材料加工で身に付けさせたい技能だからです。

3D-CADは、紙の図面をすべて置き換えるための道具ではなく、**紙ではできない、または難しいことを行うための道具**として扱いたいと考えています。

例えば、次の用途です。

- 寸法を変えた複数案を比較する
- 部品同士の干渉を確認する
- 組み立て前に構造を検討する
- 限られた材料内で木取りを検討する
- 形状を3Dプリンタや加工機へ渡す
- 同じ設計データを複数媒体へ展開する

木工教材のモデリングだけを目的にするなら、創WebやcaDIY3D for Educationの方が、Tinkercadより円滑に進む可能性があります。

しかし、それを生徒が初めて触る唯一のCADにするかどうかは別の判断です。

専用CADを採用するなら、木工の本題へ時間を振り向けられる利点と、他のCADへ移せる概念を明確にします。

<a id="selection"></a>
## 13. 目的別の選定

現時点では、次のように整理しています。

### GIGA端末から短時間で3Dプリントを体験する

**Tinkercad**

- 操作開始までの負担が小さい
- テンプレートを使える
- Classroomsで教員が作品を確認・救出できる
- Windows、Chromebook、iPadへ展開しやすい
- 学校外でも継続利用しやすい

iPadでは専用アプリを推奨します。

### 寸法・拘束・設計変更・機械製図を学ぶ

**Onshape**

- 本格的なパラメトリックCAD
- クラウド上の一つの正本
- Classes & Assignments
- Windows / Chromebook / iPadをまたいで継続できる
- 機械設計の考え方へ発展できる

iPadでは専用アプリを推奨し、教員のクラス管理はPCブラウザ中心で行います。

### iPadを本格的な3D設計端末として使う

**Shapr3D**

- iPad + Apple Pencilとの親和性が高い
- Windows版とのSyncが可能
- ソリッドモデリングを直感的に扱える

ただし、Chromebookには展開できず、教育ライセンスやクラス管理を含めた学校運用は別途検討が必要です。

### 木工作品の部品・組み立て・木取りを扱う

**創WebまたはcaDIY3D for Education**

- 板材と材料規格へ最適化されている
- 部品図、組み立て図、木取り図へつなげやすい
- caDIY3D for EducationはWindows / Chromebook / iPadのWeb利用とクラス・提出管理も備える

ただし、どちらも卒業後に生徒が同じ環境を使い続けることは難しくなります。初めてのCADとして採用する場合は、専用操作だけで終わらせず、他の環境へ移せる概念を明示する設計が必要です。

### 情報Ⅱで3Dコンテンツを制作する

**Blender**

- 画像、映像、アニメーション、3Dプリントへ展開できる
- OSSであり、Application Templateによる授業用構成を検討できる
- 端末間でバージョンをそろえやすい
- ファイル管理と3Dプリント適合検査は別途設計する

## 14. 次に検証すること

次の優先対象は、caDIY3D for Educationです。

公式情報だけでなく、教員用1アカウント、生徒想定の複数アカウント、異なる端末を使い、次を確認します。

1. 教員がクラスを作成する
2. 生徒を登録する
3. ひな形または参考図面を配布する
4. Chromebook / iPad / Windowsから操作する
5. 生徒が設計する
6. 別端末から同じ作品を開く
7. 教員が途中状態を確認できる範囲を確認する
8. 生徒が提出する
9. 教員が確認・返却する
10. 生徒が提出に失敗した場合に作品を救出できるか確認する
11. STL等へ書き出し、スライサーへ渡す
12. 年度更新と卒業時のデータ取扱いを確認する

創Webについては、現行版の保存方式、Chromebookでの利用、教員管理機能を確認します。

Shapr3Dについては、今回の主要導線からは外しますが、iPad中心校における可能性として、

- iPadでのモデリング
- WindowsへのSync
- STL / 3MF出力
- 教育ライセンス
- 生徒作品の教員管理

を必要に応じて検証します。

Blenderについては、次の順で検討します。

1. `.blend`テンプレート
2. Application Template
3. Pythonアドオン
4. それでも不足する場合だけ本体改変

<a id="summary"></a>
## 15. まとめ

学校で3Dモデリング環境を選ぶとき、機能数の多さだけでは判断できません。

必要なのは、次の問いです。

- 生徒は授業時間内に作業を始められるか
- GIGA端末とPC教室のどちらで使うのか
- 教員は操作の意味を理解し、支援できるか
- 作品の正本はどこにあるか
- 端末を替えて続けられるか
- 提出に失敗しても救出できるか
- 学校外でも使い続けられるか
- 紙の図面では難しい何を実現するのか

短時間の3Dプリント入門では、Tinkercadが有力でした。

目的が変われば候補も変わります。

- 機械設計を学ぶ：Onshape
- iPadを本格的な設計端末として使う：Shapr3D
- 木工作品の設計を効率化する：創Web、caDIY3D for Education
- 3Dコンテンツを制作する：Blender

私は、生徒が初めて触るCADを、卒業後に使えない製品固有操作だけへ閉じたくありません。

一方、専用CADが本題へ時間を振り向け、教員による確認・救出まで支えるなら、その価値も正しく評価する必要があります。

優劣ではなく、

> **何を学ばせ、どの端末で使い、作品をどう守り、学んだことを次へどこまで持ち出せるようにするか。**

その判断を、モデリング機能だけでなく、保存・提出・復旧・製造・卒業後まで含めて行います。
